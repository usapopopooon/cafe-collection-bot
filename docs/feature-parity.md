# Cafe feature parity

新Botは旧Botの代替操作をすべて提供し、両Botを同時に利用できます。状態と取引は
level-botの同じトランザクションAPIを通るため、どちらから操作しても結果は共通です。

| 旧Botの機能 | 新Botでの操作 |
| --- | --- |
| 1枚抽選 | パネル「1枚引く」 / `/cafe draw` |
| 最大10枚のまとめ引き（残り枠・XPに自動調整） | パネル「まとめて引く（最大10枚）」 |
| XP残高・無料枠・時間枠 | パネル「自分のXP・残り枠」 / `/cafe balance` |
| 全レアリティのカード棚 | パネル「自分の棚・重複交換」 / `/cafe collection` |
| お気に入りカード | カード棚「お気に入り」 |
| 個別XP交換（1枚・全枚・枚数指定） | カード棚「個別XP交換」 |
| 全重複のXP交換 | カード棚「全重複をXPへ」 |
| 全重複のカフェメダル交換 | カード棚「全重複をメダルへ」 |
| カード保護・解除、苔コーラ簡易保護 | カード棚 / `/cafe protect` |
| メダル残高・棚テーマ購入／装備 | カード棚「メダル・棚テーマ」 |
| セットメニュー帳 | カード棚「セットメニュー」 |
| Web図鑑・排出率 | パネル「Web図鑑・排出率」 |
| 全10部門ランキング・本人順位 | `/cafe ranking` で設置するランキングパネル |
| 利用状況・XP収支 | `/cafe stats` |
| 利用ロール追加・削除・一覧 | `/cafe access-role add` / `remove` / `list` |
| パネル・台帳・ランキング設置 | `/cafe panel` / `ledger` / `ranking` |

## 併用時の一意性

- 抽選とXP交換はDiscord操作IDを冪等キーにし、再送しても同じ取引を二重確定しません。
- 残高、無料枠、時間枠、カード所持、保護、お気に入り、メダル、棚テーマは共通DBの
  同じロックと取引を使用します。
- 旧Botと新Botは、自分に設定された台帳チャンネルへそれぞれ投稿します。両方に設定が
  あれば同じ確定取引を両方へ1回ずつ掲載し、投稿済みIDもBot別に保持します。
