# Cafe black-box UI contract

移行時に確認した `level-bot` のカフェ機能を基本のUI契約とします。
トップレベルコマンド名は `/cafe-collection` に統一し、既存機能の権限、取引内容、
公開投稿の宛先は維持します。カード棚の重複交換は以下の操作性改善を反映します。
移行やBot構成を説明するDiscord表示は追加しません。

| 機能 | 新Botの操作 |
| --- | --- |
| 1枚抽選 | パネル「一枚引く」 |
| 最大10枚のまとめ引き（残り枠・XPに自動調整） | パネル「まとめて引く（最大10枚）」 |
| XP残高・無料枠・時間枠 | パネル「自分のXP・残り枠」 |
| 全レアリティのカード棚 | パネル「自分の棚・重複交換」 |
| お気に入りカード | カード棚の「お気に入りするカードのレアリティを選ぶ」選択欄 |
| 個別XP交換（1枚・全枚・枚数指定） | カード棚「重複を選んでXP交換」 |
| 全重複のXP交換 | カード棚「全重複をXP交換」 |
| 全重複のカフェメダル交換 | カード棚「全重複をメダル交換」 |
| レアリティ別のXP・メダル交換 | カード棚「レアリティ別XP交換」「レアリティ別メダル交換」からレアリティを選ぶ |
| カード保護・解除、苔コーラ簡易保護 | カード棚 / `/cafe-collection protect` |
| メダル残高・棚テーマ購入／装備 | カード棚「メダル・棚テーマ」 |
| セットメニュー帳 | カード棚「セットメニュー」 |
| Web図鑑・排出率 | パネル「Web図鑑・排出率」 |
| 全10部門ランキング・本人順位 | `/cafe-collection leaderboard-panel` で設置するランキングパネル |
| 利用状況・XP収支 | `/cafe-collection stats` |
| 利用ロール追加・削除・一覧 | `/cafe-collection access-role add` / `remove` / `list` |
| カウンター・台帳・抽選パネル作成／修復 | `/cafe-collection setup` |

カード棚は操作ボタンを先に表示し、棚画像からも「交換・保護メニュー」を開けます。
棚画像はレアリティと前後ページで必要な40種分だけ表示します。
お気に入りと個別XP交換のカード選択もレアリティごとに
25種ずつ表示し、個別XP交換ではカード名の一部から検索できます。
大量のカードを所持してもDiscordの選択肢上限を超えず、画像の生成に失敗しても
交換ボタンを操作できます。
交換ボタンはXPのカード別・レアリティ別・全重複、メダルのレアリティ別・
全重複の順に並べます。交換ボタンを押すたびに最新の所持数を取得するため、
以前開いた棚のボタンからでも古い枚数では確認しません。
レアリティ別交換では、選択したレアリティの交換可能な
重複だけを対象にし、カード名の一部・枚数・受取額を確認してから確定します。
全重複交換ではレアリティごとの枚数と受取額を確認できます。
XP・メダルともに確認画面からキャンセルできます。交換成功後は同じ画面に
最新の棚と操作ボタンを表示します。棚の再取得だけ失敗した場合も交換成功を伝えます。

抽選操作の非公開応答にはカード画像や結果カードを表示しません。成功時はカフェ台帳を
確認する案内と現在XPだけを返し、カード画像は設定済みのカフェ台帳だけに投稿します。
カフェ台帳に説明用の見出しカードは置きません。

## 取引の一意性

- 抽選とXP交換はDiscord操作IDを冪等キーにし、再送しても同じ取引を二重確定しません。
- 残高、無料枠、時間枠、カード所持、保護、お気に入り、メダル、棚テーマは共通DBの
  同じロックと取引を使用します。
- 台帳はこのBotに設定されたチャンネルへ投稿し、投稿済みIDを保持して再試行時の
  重複投稿を防ぎます。
