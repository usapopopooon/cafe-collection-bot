# Cafe Collection separation boundary

## 現在の状態

このリポジトリはDiscordのカフェ機能、サイト向け公開API、カード画像510枚を所有します。
`level-bot` はカフェ機能をDiscordへ登録せず、カード画像も配信しません。

カフェ・コレクションのドメイン実装、DBモデル、マイグレーション、XPを含む取引、公開データの
正本は引き続き `level-bot` が所有します。サイトはこのBotのAPIを参照し、このBotは
level-botの公開データAPIを上流として中継します。

## 実行時の責務

- Discordコマンド、パネル、応答、台帳投稿、ランキング投稿はこのBotだけが担当する。
- カード画像とサイト向け公開URLはこのBotだけが配信する。
- 抽選・交換・保護・設定などの状態変更はlevel-botの専用内部APIを通す。
- 図鑑・ランキング・個人棚の公開JSONはlevel-botを上流としてこのBotが中継する。
- level-botに残す画像マニフェストは、内部APIの互換性確認にだけ使う。
- level-botの `CAFE_COLLECTION_PUBLIC_API_ENABLED` は公開データの上流を移すまで無効化しない。

## 安全上の制約

カード残高の確認と消費を別プロセス間の単純な読取・書込に分けると競合が起きます。
DBを分離する場合は、冪等なイベントIDを持つ予約・確定APIまたは同等のトランザクション
プロトコルを先に導入します。

抽選は共通APIへDiscord操作IDを冪等キーとして渡します。台帳の投稿済みIDはこのBotが
保持し、一時的な投稿失敗を再試行しても重複投稿しません。
